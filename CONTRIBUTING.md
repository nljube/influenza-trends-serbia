# Contributing

This is a portfolio research repository, so contributions should keep the project focused, reproducible, and scientifically cautious.

Before opening a pull request:

- Keep all documentation in English.
- Do not add fabricated data, figures, or results.
- Do not change epidemiological interpretation without a clear rationale.
- Keep code changes small and consistent with the existing workflow.
- Note whether generated outputs depend on non-public surveillance data.
